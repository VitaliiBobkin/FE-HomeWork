# FE-HomeWork

## Home_Work_24
## Tasks Overview

### 1. Arithmetic Mean Calculator
Calculate the arithmetic mean of numeric elements in a mixed-type array.
- Ignores non-numeric elements
- Handles empty arrays and invalid inputs
- Returns the calculated average

### 2. Mathematical Operations Function
Performs basic mathematical operations between two numbers based on a specified operator.

Supported operators:
- `+` Addition
- `-` Subtraction
- `*` Multiplication
- `/` Division
- `%` Modulus
- `^` Exponentiation

### 3. Dynamic 2D Array Creator
Creates a two-dimensional array with user-specified dimensions and values.
- User defines the length of main array
- User defines the length of each sub-array
- User provides values for each element

### 4. Character Removal Function
Removes specified characters from a string.
- Case-sensitive removal
- Handles multiple characters
- Preserves string order
